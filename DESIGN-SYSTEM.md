# Guia de Estilo & Sistema de Design — De Lucca Arquitetura | Construção

## 1. Visão Geral
- **Nome:** De Lucca Arquitetura | Construção
- **Conceito:** Minimalismo Técnico-Editorial
- **Atributos:** Precisão, sofisticação, solidez, elegância contemporânea

## 2. Paleta de Cores

| Token | Hex | Uso |
|-------|-----|-----|
| `--color-primary-dark-red` | `#8C1D24` | Botões CTA, destaques |
| `--color-secondary-terracotta` | `#C44D38` | Hovers, acentos |
| `--color-brand-charcoal` | `#2A2C2E` | Títulos, textos principais |
| `--color-technical-gray` | `#5C6268` | Textos secundários, ícones |
| `--bg-page-warm` | `#FAF8F5` | Fundo das páginas |
| `--bg-card-white` | `#FFFFFF` | Cards, modais |
| `--border-subtle` | `#E2DDD5` | Bordas, divisores |
| `--bg-footer-dark` | `#1E2022` | Rodapé |

## 3. Tipografia
- **Títulos:** `Playfair Display`, serifa
- **Corpo:** `Plus Jakarta Sans`, sans-serif
- **Detalhes técnicos:** `JetBrains Mono` (metragens, datas)

## 4. UI/UX
- Grid 12 colunas, espaçamento amplo
- `border-radius: 4px-8px` (cantos quase retos)
- Linhas finas `1px solid #E2DDD5`
- Sombras difusas: `0 4px 30px rgba(0,0,0,0.05)`
- Transições de 0.3s
- Imagens em luz natural, texturas de concreto/madeira/vidro

## 5. Páginas
1. Início (Hero + Destaques)
2. O Escritório (Sobre)
3. Projetos (Portfólio em grid)
4. Serviços
5. Contato
